# ADR-001: Asegurar el comportamiento con un golden master antes de refactorizar

- **Estado:** aceptada
- **Fecha:** 2026-10-22

## Contexto

La versión inicial no tenía pruebas y su lógica estaba mezclada con `print`, lo que impedía escribir pruebas unitarias sin modificarla primero.

## Decisión

Escribir una prueba de caracterización que ejecute la CLI real en 38 pasos y compare salida, código de salida y `datos.json` con una versión aprobada generada desde `estado-inicial`.

## Consecuencias

Se pudo refactorizar con una red de seguridad desde el primer commit. Contra: la prueba es lenta (lanza procesos) y frágil ante cambios de texto deseados; por eso las correcciones de defectos se verificaron con pruebas aparte y no modificando el golden master.
