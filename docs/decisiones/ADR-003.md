# ADR-003: Inversión de dependencias con `typing.Protocol`

- **Estado:** aceptada
- **Fecha:** 2026-10-22

## Contexto

El servicio necesitaba persistencia, notificación y fecha actual, pero acoplarse a `open()`, `print` y `datetime.now()` hacía imposible probarlo.

## Decisión

Definir protocolos (`RepositorioSolicitudes`, `ConsultaSolicitudes`, `Notificador`) e inyectar las implementaciones y el reloj por constructor. Se eligió `Protocol` (tipado estructural) en lugar de clases abstractas para no obligar a heredar.

## Consecuencias

Pruebas rápidas con fakes, stubs y mocks. Cambiar JSON por una base de datos implica una clase nueva, no reescribir el servicio.
