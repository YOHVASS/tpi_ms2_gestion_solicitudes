# ADR-005: CLI con tabla de despacho propia en lugar de argparse

- **Estado:** aceptada
- **Fecha:** 2026-10-22

## Contexto

`argparse` habría sido la opción idiomática, pero cambia los mensajes de uso y devuelve código de salida 2, lo que alteraría el comportamiento externo aprobado.

## Decisión

Mantener el parseo manual, pero ordenado en una tabla `COMANDOS` con una función pequeña por comando y su cantidad mínima de argumentos.

## Consecuencias

Se conservan mensajes y códigos de salida. Queda como mejora futura migrar a `argparse` en una versión que acepte cambiar la interfaz.
