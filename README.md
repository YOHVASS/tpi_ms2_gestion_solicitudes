# Gestión de Solicitudes Académicas

Prototipo por consola para registrar y seguir solicitudes de estudiantes.

## Uso

```
python app.py init
python app.py registrar 1001 certificado alta "Certificado de alumno regular"
python app.py asignar 4 R1
python app.py estado 4 en_proceso
python app.py buscar estado=pendiente
python app.py reporte
```
